# scoop-crimlab

[Scoop](https://scoop.sh) bucket for [crimlab](https://github.com/rootcoder007/crimlab), a Statistical Toolkit for Criminology and Sociolegal Research, from the command line.

```powershell
scoop bucket add crimlab https://github.com/rootcoder007/scoop-crimlab
scoop install crimlab/crimlab
```

The manifest installs the release zip for x64, checked against its SHA-256, and puts `crimlab` on PATH. `scoop update crimlab` follows new releases. Documentation: <https://crimlab.dev/>.
